• O MNIE

Ekonomia na studiach,
kod po godzinach.

Uczę się, jak działają pieniądze i rynki, a w wolnym czasie piszę strony i aplikacje. Lubię, kiedy coś działa szybko, wygląda porządnie i nie trzeba czytać instrukcji, żeby z tego korzystać.

Nie składam stron z gotowych klocków. Każdą piszę od pierwszej linijki, więc mogę zrobić dokładnie to, czego potrzebujesz.

HTML / CSS / JS three.js Vercel GitHub Claude
01

Pomysł

Mówisz, co chcesz osiągnąć. Ja dopytuję, aż oboje wiemy, co budujemy.

02

Projekt i kod

Pokazuję wersję roboczą wcześnie, żebyś mógł zmienić kierunek, zanim będzie za późno.

03

Start

Strona trafia do sieci, a ja zostaję pod telefonem, gdy trzeba coś poprawić.
